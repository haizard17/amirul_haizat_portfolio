HAZERD PORTFOLIO — SETUP

1. Open index.html in a browser to preview.
2. Replace the placeholder blocks with your own images.
   Recommended location: assets/images/
3. To use an image, replace a placeholder like:
   <div class="project-image placeholder green"><span>YOUR...</span></div>
   with:
   <div class="project-image"><img src="assets/images/your-image.jpg" alt="Project description"></div>
4. Add your actual resume at assets/Hazerd-Resume.pdf
5. Replace the email, LinkedIn URL and WhatsApp number in index.html.
6. Upload the entire folder to your hosting provider.

Suggested image filenames:
assets/images/bumimas-packaging.jpg
assets/images/uitm-jasin-go.jpg
assets/images/ice-cream-display.jpg
assets/images/digital-content-01.jpg

The site is static HTML/CSS/JS, so it works on standard web hosting without a backend.
